# Helper для бизнеса — кабинет партнёра

Веб-кабинет для компаний-партнёров Helper: автосервисов, моек, шиномонтажей, АЗС, страховых и т. д.
Компания регистрируется сама и сразу попадает в свой кабинет. Интерфейс — на русском, румынском и английском; рынок — Молдова (дальше Румыния).

Клиенты с приложением Helper приходят к партнёру; кассир отмечает визит по Helper-коду (водитель получает
**километры Helper** и опыт от Helper, партнёр — опыт партнёра) и выдаёт **плюшки** — бесплатные услуги и подарки,
которые водители бронируют за километры. Партнёр растёт в уровнях (Бронза → Платина), выполняет квесты, видит оценки
клиентов и «спрос рядом», запускает акции для водителей рядом и видит обезличенную статистику.

**Игровая модель** (`04_AUTOMATION/docs/GAME_MODEL.md`, API — `docs/GAME_API.md`): у километров Helper нет денежной
стоимости — кабинет нигде не показывает цену километра в деньгах; партнёр за километры не платит и денег за них не
получает; сумма чека не вводится; скидки — только в акциях (реклама), не в плюшках. Баланс партнёра расходуется только
на рекламу (показы акций, гео-уведомления сверх бесплатной квоты уровня). Названия: «километры Helper» /
«kilometri Helper» / «Helper kilometres» (коротко «км Helper»), плюшки — «Плюшки» / «Beneficii» / «Perks».

## Как открыть

- Рабочий адрес: <https://dmitriimalahov-gif.github.io/helper-app/partner/>
- На телефоне кабинет можно добавить на экран «Домой» (есть `manifest.webmanifest`, ярлык «Касса»).
- Адрес API берётся из `../config.json` — тот же файл, что у приложения водителя. Файл подписан
  (`{"api", "v": 1, "iat", "sig"}`, ECDSA P-256): кабинет принимает его, только если подпись верна и `api` — https
  без пути, логина и параметров. В кэш (`helper.partner.cfg.v2`) попадает только проверенный подписанный объект,
  при чтении из кэша подпись проверяется заново.
- Для разработки адрес API можно подменить параметром `?api=` — **только если сам кабинет открыт с `127.0.0.1`
  или `localhost`**: `http://127.0.0.1:8766/partner/?api=http://127.0.0.1:8070`. Разрешены https-адреса и http только
  на локальные/частные адреса (`127.0.0.1`, `localhost`, `10.*`, `192.168.*`, `172.16–31.*`). Значение сохраняется
  на устройстве (`localStorage`, ключ `helper.partner.api`); вернуть адрес из `config.json`: `?api=default`.
  На любом другом адресе (GitHub Pages) параметр игнорируется и убирается из адресной строки, а сохранённое
  переопределение удаляется при запуске — ссылка вида `…/partner/?api=https://чужой-сервер` не уводит логин и токены.
- Локально: `python3 -m http.server 8766` в папке `06_WEB`, затем <http://127.0.0.1:8766/partner/>.
  Камера в браузере работает только на `https://` или `localhost`/`127.0.0.1`.

## Что умеет

| Раздел | Что делает |
|---|---|
| Главная | Статус компании, чек-лист (точки, первая плюшка, акция, кассиры), баланс с пометкой «Баланс — только для рекламных кампаний» и остатком бесплатных гео-уведомлений, за 7 дней: визиты (новые/повторные клиенты), выданные плюшки, оценка, уровень партнёра; карточка «Моя игра» (прогресс уровня, ближайший квест), последние операции, активные плюшки и акции. |
| Касса | Две большие кнопки: **«Отметить визит»** (сканировать Helper-код) и **«Выдать плюшку»** (сканировать купон). Сканер камерой (задняя камера, фонарик, вибрация), «Из фото», ручной ввод; что отсканировано — решает сервер (`GET …/client`). Карточка клиента — только Helper ID, уровень, значки, «новый/уже был у вас» и купоны на плюшки этого партнёра; необязательный вид услуги (тег для квестов), точка; «Засчитать визит» → «Визит засчитан: клиенту +20 км Helper и +30 опыта, вам +5 опыта партнёра» + прогресс уровня партнёра. Лимиты и ошибки сервера показываются как есть (визит сегодня уже засчитан, дневной лимит визитов, сотрудник не может отметить себя, визит на проверке). Купон → вид плюшки, срок, счастливые часы → «Плюшка выдана». Журнал: визиты и выданные плюшки. Суммы чека и денежной цены баллов больше нет. |
| Плюшки | Вместо «Наград». Список со статусами (черновик, на модерации, активна, пауза, отклонена + причина модерации), лимитами, расписанием и счётчиками (забронировано / выдано / сегодня); опубликовать, пауза, возобновить, удалить. Бывшие награды-скидки — черновики с пометкой «Переделайте в бесплатную услугу или подарок». Шаблоны по категории компании (`GET …/perks/templates`, запасной набор — GAME_MODEL §7) — один клик заполняет форму на трёх языках. Редактор: вид (услуга / подарок / без очереди / бесплатная опция), название и описание RU/RO/EN, цена ползунком только внутри рекомендованного коридора вида, минимальный уровень водителя, лимит в день/месяц, счастливые часы (дни и часы), точки, срок купона, повторная бронь; правило «Плюшка — бесплатная услуга или подарок. Скидки и деньги сюда не добавляются — для скидок используйте акции» и проверка текста на «%», «скидк», «лей», «MDL» и т. п.; предпросмотр карточки в приложении водителя RU/RO/EN. |
| Моя игра | Уровень партнёра (Бронза / Серебро / Золото / Платина), опыт и прогресс до следующего; что даёт уровень сейчас и на следующем (место в ленте, значок, сезонные события, бесплатные гео-уведомления в месяц с использованием за месяц, «Партнёр месяца»); квесты партнёра с шагами; оценки (средняя, распределение, теги, последние отзывы — только при ≥ k оценок, анонимно; ответа на отзывы API не предусматривает); «Спрос рядом» («у 34 водителей в 3 км скоро: замена масла», кнопки «Плюшка» и «Акция для них»), при недостатке данных — «Мало данных» с пояснением; как растёт опыт; последние начисления опыта. |
| Акции | Список со статусами и мини-статистикой; мастер создания/правки: тип (скидка — реклама партнёра, километры ×N за визит, объявление), текст со счётчиками, плюшка акции (`perk_id`), период, точки, радиус, аудитория (топливо, марки, возраст авто, «кому скоро нужно»), каналы (лента, гео-уведомление — сначала бесплатная квота уровня), бюджет. Живой предпросмотр карточки в приложении водителя. Запуск, пауза, возобновление, копия, удаление; статистика по акции. |
| Точки | Карта Leaflet/OpenStreetMap со всеми точками и радиусами; добавление и правка: «Я сейчас здесь», поиск адреса (Nominatim, только по кнопке «Найти»), перетаскиваемый пин, радиус, часы работы. |
| Статистика | Период 7/30/90 дней, плитки: визиты (новые/повторные), выданные плюшки, оценка, уровень, показы, уведомления, проходы рядом, расходы на рекламу; графики Chart.js по дням (визиты; показы и уведомления; проходы и выданные плюшки), таблица акций. Значения `"<5"` показываются как «меньше 5» с пояснением про k-анонимность. |
| Сотрудники | Только владелец: список, приглашение по роли (ссылка, QR, копирование, «Поделиться»), смена роли, удаление. |
| Баланс | Баланс — только для рекламных кампаний; бесплатные гео-уведомления уровня (осталось / всего, тратятся раньше баланса); пополнение картой через Stripe Checkout (с возвратом в кабинет), счёт на банковский перевод, история счетов. |
| Настройки | Профиль компании, предложение в карточке компании (реклама: текст и постоянная скидка), смена компании, вступление по коду приглашения, выход. «% чека баллами» и лимит баллов удалены. |

Регистрация (4 шага, данные из `GET /v1/partner/meta` и `/v1/geo/*`): компания, страна, город и телефон с кодом страны → контакт и аккаунт (или «У меня уже есть аккаунт Helper») →
первая точка на карте → «Как работает игра Helper» (визит, плюшка, уровень — значения из справочника игры) и принятие оферты.
После `POST /v1/partner/register` сразу открывается кабинет с чек-листом. Пока компания на проверке (`pending`),
вверху показывается баннер: кабинет работает, но отметка визитов, выдача плюшек и показ акций клиентам включатся после одобрения.

## Языки и страна

- **Языки:** русский, румынский, английский (`ru` / `ro` / `en`). Переключатель «RU · RO · EN» — в шапке лендинга,
  мастера регистрации и кабинета (на компьютере — справа вверху), а также в меню «Ещё», в листе «Компания и аккаунт»
  и в «Настройках». Язык выбирается так: сохранённый выбор (`localStorage`, ключ `helper.partner.lang`) → язык
  браузера (`mo`, `ro-MD` → `ro`) → `en` (если ни выбора, ни подходящего языка браузера нет — язык компании).
- Все тексты — в словаре `TX` внутри `index.html` (ключ → `[ru, ro, en]`), функции `tx()` / `tp()` (множественное
  число через `Intl.PluralRules`: «1 punct · 2 puncte · 20 de puncte») / `tl()` (текст на заданном языке — для
  предпросмотра). Числа, деньги, даты, расстояния — через `Intl` (`ru-RU`, `ro-RO`, `en-GB`). Новый язык = ещё
  один столбец в словаре + строка в `LANGS`/`LOCALE`. Шрифт Montserrat подключается с `latin-ext` (ș ț ă â î).
- Каждый запрос к API идёт с `Accept-Language`, запросы к Nominatim — с `accept-language`. Справочники сервера
  (категории, роли, статусы, пакеты) показываются по ключу из словаря; ошибки сервера — текстом сервера, если он на
  нужном языке, иначе переводом по коду ошибки.
- **Страна, код телефона, город** (регистрация, «Настройки → Профиль компании», точки): выпадающие списки с поиском
  (без учёта регистра и диакритики: «balti» найдёт «Bălți»). Страна — флаг, название на языке интерфейса и код;
  сверху Молдова, Румыния, Украина (`GET /v1/geo/countries`). Код телефона привязан к стране, но его можно сменить;
  длина номера проверяется по `phone_digits`, на сервер уходит E.164 (`+37369123456`; ведущий 0 национального
  формата отбрасывается). Город — список городов страны (`GET /v1/geo/cities`) с официальным местным названием
  подсказкой и пунктом «Другой город…» (текстом, с поиском через Nominatim по кнопке «Найти»).
- **Предвыбор:** при открытии мастера `GET /v1/geo/hint` выставляет страну и код. Кнопка «Определить по геолокации»
  (и «Я сейчас здесь» на шаге с картой) берёт геолокацию браузера → `GET /v1/geo/reverse` → страна и город, карта
  открывается на этой точке. Если разрешение на геолокацию уже дано, определение запускается само. Выбор города
  вручную центрирует карту на этом городе.
- **Без геолокации или без `/v1/geo/*`** всё работает: страна — по подсказке сервера или по региону языка браузера,
  список стран — из `Intl.DisplayNames` и встроенной таблицы кодов (MD, RO, UA и основные страны Европы), город —
  текстом.
- Язык компании (`lang`) при регистрации = язык интерфейса; меняется в «Настройках». На нём письма и уведомления и
  оригинал новых акций.
- **Акции на нескольких языках:** в редакторе (шаг «Текст») вкладки языков: язык компании — оригинал, остальные —
  необязательные переводы (`Campaign.lang`, `Campaign.i18n`). Предпросмотр карточки переключается RU/RO/EN (нет
  перевода — показывается оригинал с пометкой). Плюшки переводятся так же: название и описание (`Perk.lang`, `Perk.i18n`), предпросмотр карточки плюшки — тоже RU/RO/EN. В ленте
  приложения `GET /v1/offers?lang=…` отдаёт перевод, если он есть.
- Подпись валюты — из `partner.currency` (если есть); все суммы по-прежнему в MDL (открытый вопрос контракта).
- Контракт: `04_AUTOMATION/docs/I18N_GEO_API.md`. Скриншоты проверки: `screenshots/i18n/` (390×844 и 1440×900).

## Роли

| | Владелец | Менеджер | Кассир |
|---|---|---|---|
| Касса (визит, выдача плюшки, операции) | ✓ | ✓ | ✓ |
| Главная, плюшки, моя игра, акции, точки, статистика, баланс, настройки | ✓ | ✓ | — |
| Удаление (акции, точки, плюшки) | ✓ | — | — |
| Сотрудники и приглашения | ✓ | — | — |

Кассир видит только «Кассу» (на телефоне — без нижнего меню) и меню аккаунта (смена компании, выход).
Кнопки скрываются по роли и по `permissions` из `GET /v1/partner/{pid}`; сервер в любом случае проверяет права сам.

## Вход, магические ссылки и приглашения

- Аккаунты и токены — те же, что в приложении Helper (`/v1/auth/login|register|refresh|logout`).
  Токены кабинета хранятся отдельно от приложения водителя (`localStorage`, ключ `helper.partner.acct.v1`);
  при ответе 401 кабинет один раз обновляет токен (`/v1/auth/refresh`) и повторяет запрос.
- **Магическая ссылка** из Telegram-бота: `…/partner/#magic=<token>` (живёт 15 минут, одноразовая).
  Кабинет сразу убирает токен из адресной строки, вызывает `POST /v1/auth/magic` и входит.
  Просроченная или использованная ссылка → понятное сообщение и форма входа по e-mail.
- **Приглашение сотрудника**: владелец в «Сотрудниках» выбирает роль и получает ссылку `…/partner/#join=<code>` и QR.
  Сотрудник открывает ссылку, входит или создаёт аккаунт Helper — кабинет вызывает `POST /v1/partner/join`
  и открывает компанию (кассира — сразу на «Кассе»). Код одноразовый, живёт 7 дней; ввести код или ссылку
  можно и вручную (экран «нет компании», «Настройки»).
- Если пользователь состоит в нескольких компаниях, выбранная компания запоминается на устройстве
  (`helper.partner.pid`), сменить её можно в меню компании.

## Оплата

«Оплатить картой» → `POST /v1/partner/{pid}/topup` → переход на `checkout.stripe.com`. После оплаты Stripe
возвращает в кабинет (`#/billing?topup=success|cancel`, также понимается `#topup=success|cancel`);
кабинет показывает результат и несколько раз обновляет баланс, пока вебхук не зачислит платёж.
Данные карты вводятся только на странице Stripe. «Счёт на перевод» формирует реквизиты для банковского платежа.

## Коды на кассе

Сканер принимает QR `HELPER:HLP-XXXXXX` и штрихкод Code128 `HLP-XXXXXX` (клиент), QR `HELPER-COUPON:<код>`
и штрихкод с кодом купона (купон на плюшку). Режим кассы («Отметить визит» / «Выдать плюшку») меняет только подсказки:
отсканированный купон всегда открывает выдачу плюшки, Helper-код — карточку клиента (в режиме плюшки его купоны — сверху). Распознавание: `BarcodeDetector` браузера, если он есть (Chrome/Android),
иначе ZXing (Safari/iPhone). Всё, что отсканировано, отправляется в `GET /v1/partner/{pid}/client` —
сервер сам определяет, клиент это или купон.

## Приватность

Кабинет не получает имён, телефонов, e-mail и координат клиентов — только Helper ID. Фильтры аудитории акций
проверяются на телефоне водителя. В статистике группы меньше 5 человек скрыты («меньше 5»).

## Техническое

- Один файл `index.html` (HTML + CSS + JS без сборки), плюс `manifest.webmanifest`, `sw.js`, иконки и логотипы.
- Свой service worker `sw.js` (scope `/partner/`) пустой: ничего не кэширует, кабинет всегда загружается из сети.
  Он нужен, чтобы страницы кабинета не обрабатывал service worker приложения водителя (scope `/helper-app/`).
- Внешние библиотеки подгружаются по требованию с CDN с проверкой целостности (SRI): Leaflet 1.9.4 (cdnjs),
  Chart.js 4.5.1, @zxing/library 0.21.3, qrcode-generator 1.4.4 (jsDelivr). Карта — тайлы OpenStreetMap,
  поиск адреса — Nominatim (запрос только по кнопке, не чаще раза в секунду).
- Шрифт Montserrat (Google Fonts), фирменные цвета и компоненты — как в приложении водителя; тёмная тема
  по `prefers-color-scheme`. Телефон: нижнее меню; компьютер (от 960 px): боковое меню.
- Контракт API: `04_AUTOMATION/docs/PARTNER_API.md`, игра — `04_AUTOMATION/docs/GAME_API.md` (§7 касса, §8 плюшки,
  §9 «Моя игра», §10 изменения). Справочник игры (`GET /v1/game/meta`) кэшируется на устройстве
  (`helper.partner.gmeta.v1.<lang>`); без него действуют значения GAME_MODEL (визит +20 км / +30 опыта, коридоры цен).
- Тексты сервера, которые приходят только по-русски (вид и статус плюшки, теги оценок, правила опыта, вид услуги в
  журнале), в RO/EN показываются по ключу из словаря кабинета.
- Скриншоты проверки: `screenshots/` (390×844 и 1440×900), игровая модель — `screenshots/game/` (ru и ro).
