# Helper для бизнеса — кабинет партнёра

Веб-кабинет для компаний-партнёров Helper: автосервисов, моек, шиномонтажей, АЗС, страховых и т. д.
Компания регистрируется сама и сразу попадает в свой кабинет. Интерфейс — на русском; рынок — Молдова (дальше Румыния).

Клиенты с приложением Helper приходят к партнёру; партнёр начисляет им баллы с чека и принимает купоны,
запускает акции для водителей рядом со своими точками и видит обезличенную статистику.

## Как открыть

- Рабочий адрес: <https://dmitriimalahov-gif.github.io/helper-app/partner/>
- На телефоне кабинет можно добавить на экран «Домой» (есть `manifest.webmanifest`, ярлык «Касса»).
- Адрес API берётся из `../config.json` (поле `api`, без кэша) — тот же файл, что у приложения водителя.
- Для разработки адрес API можно подменить параметром `?api=`:
  `http://127.0.0.1:8765/partner/?api=http://127.0.0.1:8070` — значение сохраняется на устройстве
  (`localStorage`, ключ `helper.partner.api`). Вернуть адрес из `config.json`: `?api=default`.
- Локально: `python3 -m http.server 8765` в папке `06_WEB`, затем <http://127.0.0.1:8765/partner/>.
  Камера в браузере работает только на `https://` или `localhost`/`127.0.0.1`.

## Что умеет

| Раздел | Что делает |
|---|---|
| Главная | Статус компании, чек-лист первых шагов, баланс, показатели за 7 дней, активные акции, последние операции. |
| Касса | Сканирование QR/штрихкода камерой (задняя камера, фонарик, вибрация), распознавание «Из фото», ручной ввод. Helper ID → карточка клиента: купоны клиента у этого партнёра, сумма чека с живым расчётом баллов, выбор точки (запоминается на устройстве) и бонусной акции, «Начислить» → экран успеха → «Следующий клиент». Купон → подтверждение → погашение. Журнал операций. |
| Акции | Список со статусами и мини-статистикой; мастер создания/правки: тип (скидка, бонусные баллы ×N, объявление), текст со счётчиками, купон за баллы, период, точки, радиус, аудитория (топливо, марки, возраст авто, «кому скоро нужно»), каналы (лента, гео-уведомление), бюджет. Живой предпросмотр карточки в приложении водителя. Запуск, пауза, возобновление, копия, удаление; статистика по акции. |
| Точки | Карта Leaflet/OpenStreetMap со всеми точками и радиусами; добавление и правка: «Я сейчас здесь», поиск адреса (Nominatim, только по кнопке «Найти»), перетаскиваемый пин, радиус, часы работы. |
| Статистика | Период 7/30/90 дней, плитки показателей, графики Chart.js по дням, таблица акций. Значения `"<5"` показываются как «меньше 5» с пояснением про k-анонимность. |
| Награды | Что клиент получает за баллы: скидка %, скидка MDL или подарок; включение/выключение. |
| Сотрудники | Только владелец: список, приглашение по роли (ссылка, QR, копирование, «Поделиться»), смена роли, удаление. |
| Баланс | Баланс, пополнение картой через Stripe Checkout (с возвратом в кабинет), счёт на банковский перевод, история счетов. |
| Настройки | Профиль компании, % чека баллами с примером, дневной лимит баллов, постоянное предложение и скидка, смена компании, вступление по коду приглашения, выход. |

Регистрация (4 шага, данные из `GET /v1/partner/meta`): компания → контакт и аккаунт (или «У меня уже есть аккаунт Helper») →
первая точка на карте → % чека баллами с примером «чек 1000 MDL → N баллов, стоимость для вас X MDL» и принятие оферты.
После `POST /v1/partner/register` сразу открывается кабинет с чек-листом. Пока компания на проверке (`pending`),
вверху показывается баннер: кабинет работает, но начисление баллов и показ акций клиентам включатся после одобрения.

## Роли

| | Владелец | Менеджер | Кассир |
|---|---|---|---|
| Касса (клиент, начисление, купоны, операции) | ✓ | ✓ | ✓ |
| Главная, акции, точки, награды, статистика, баланс, настройки | ✓ | ✓ | — |
| Удаление (акции, точки, награды) | ✓ | — | — |
| Сотрудники и приглашения | ✓ | — | — |

Кассир видит только «Кассу» (на телефоне — без нижнего меню) и меню аккаунта (смена компании, выход).
Кнопки скрываются по роли и по `permissions` из `GET /v1/partner/{pid}`; сервер в любом случае проверяет права сам.

## Вход, магические ссылки и приглашения

- Аккаунты и токены — те же, что в приложении Helper (`/v1/auth/login|register|refresh|logout`).
  Токены кабинета хранятся отдельно от приложения водителя (`localStorage`, ключ `helper.partner.acct.v1`);
  при ответе 401 кабинет один раз обновляет токен (`/v1/auth/refresh`) и повторяет запрос.
- **Магическая ссылка** из Telegram-бота: `…/partner/#magic=<token>` (живёт 15 минут, одноразовая).
  Кабинет сразу убирает токен из адресной строки, вызывает `POST /v1/auth/magic` и входит.
  Просроченная или использованная ссылка → понятное сообщение и форма входа по e-mail.
- **Приглашение сотрудника**: владелец в «Сотрудниках» выбирает роль и получает ссылку `…/partner/#join=<code>` и QR.
  Сотрудник открывает ссылку, входит или создаёт аккаунт Helper — кабинет вызывает `POST /v1/partner/join`
  и открывает компанию (кассира — сразу на «Кассе»). Код одноразовый, живёт 7 дней; ввести код или ссылку
  можно и вручную (экран «нет компании», «Настройки»).
- Если пользователь состоит в нескольких компаниях, выбранная компания запоминается на устройстве
  (`helper.partner.pid`), сменить её можно в меню компании.

## Оплата

«Оплатить картой» → `POST /v1/partner/{pid}/topup` → переход на `checkout.stripe.com`. После оплаты Stripe
возвращает в кабинет (`#/billing?topup=success|cancel`, также понимается `#topup=success|cancel`);
кабинет показывает результат и несколько раз обновляет баланс, пока вебхук не зачислит платёж.
Данные карты вводятся только на странице Stripe. «Счёт на перевод» формирует реквизиты для банковского платежа.

## Коды на кассе

Сканер принимает QR `HELPER:HLP-XXXXXX` и штрихкод Code128 `HLP-XXXXXX` (клиент), QR `HELPER-COUPON:<код>`
и штрихкод с кодом купона. Распознавание: `BarcodeDetector` браузера, если он есть (Chrome/Android),
иначе ZXing (Safari/iPhone). Всё, что отсканировано, отправляется в `GET /v1/partner/{pid}/client` —
сервер сам определяет, клиент это или купон.

## Приватность

Кабинет не получает имён, телефонов, e-mail и координат клиентов — только Helper ID. Фильтры аудитории акций
проверяются на телефоне водителя. В статистике группы меньше 5 человек скрыты («меньше 5»).

## Техническое

- Один файл `index.html` (HTML + CSS + JS без сборки), плюс `manifest.webmanifest`, `sw.js`, иконки и логотипы.
- Свой service worker `sw.js` (scope `/partner/`) пустой: ничего не кэширует, кабинет всегда загружается из сети.
  Он нужен, чтобы страницы кабинета не обрабатывал service worker приложения водителя (scope `/helper-app/`).
- Внешние библиотеки подгружаются по требованию с CDN с проверкой целостности (SRI): Leaflet 1.9.4 (cdnjs),
  Chart.js 4.5.1, @zxing/library 0.21.3, qrcode-generator 1.4.4 (jsDelivr). Карта — тайлы OpenStreetMap,
  поиск адреса — Nominatim (запрос только по кнопке, не чаще раза в секунду).
- Шрифт Montserrat (Google Fonts), фирменные цвета и компоненты — как в приложении водителя; тёмная тема
  по `prefers-color-scheme`. Телефон: нижнее меню; компьютер (от 960 px): боковое меню.
- Контракт API: `04_AUTOMATION/docs/PARTNER_API.md`.
- Скриншоты проверки: `screenshots/` (390×844 и 1440×900).
