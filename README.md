# Helper — сервисная книжка автомобилиста

Веб-приложение (PWA) Helper: напоминания о ТО по пробегу, схема автомобиля с износом узлов, журнал обслуживания, расходы, бонусы партнёров.

Открыть: страница GitHub Pages этого репозитория. На телефоне: «Поделиться → На экран „Домой“».

Telegram-бот: https://t.me/HelperAutoMD_bot

Аккаунт Helper — по желанию: без входа данные хранятся только на устройстве; с аккаунтом журнал синхронизируется через API Helper (адрес — в `config.json`, поле `api`; приложения iOS/Android сначала читают `config.json` с этой страницы GitHub Pages). Premium на сайте — подписка Stripe (1–4 авто), в Telegram — звёзды в боте, в приложениях — App Store / Google Play.

© SC NumerOM SRL, группа компаний «Dirax».

Партнёры Helper: на главной — «Мой Helper-код» (QR `HELPER:<id>` и штрихкод Code128 для кассира, рисуются без сети) и «Акции партнёров» (`GET /v1/offers`, фильтр аудитории и расстояние считаются на телефоне, координаты на сервер не отправляются). Кабинет партнёра — `partner/`.

Языки: русский (исходный), română, English. Тексты интерфейса — словари `i18n/ru.js` (источник), `i18n/ro.js`, `i18n/en.js` (в коде — `t('ключ', {параметры})`, формы множественного числа через `Intl.PluralRules`); справочник узлов и статьи — разделы `kb`/`art` в `ro.js`/`en.js` (русский оригинал — в `index.html`). Нет перевода → русский. Язык: выбор пользователя (хранится на устройстве, при входе — в аккаунте, `PATCH /v1/me {language}`) → язык пользователя Telegram (Mini App) → язык устройства → English; переключатель — на экране приветствия («RU · RO · EN») и в «Ещё → Настройки → Язык». Запросы к API идут с `Accept-Language`. Контракт — `04_AUTOMATION/docs/I18N_GEO_API.md`. Словари кэшируются `sw.js` (при их изменении поднимайте версию кэша).

Сканер техпаспорта на сайте и в Telegram: фото обрабатывается прямо в браузере (Tesseract.js загружается с jsDelivr только при первом сканировании), парсер — `scan/parser.js` (копия `07_MOBILE/scan/parser.js`, обновляется `07_MOBILE/scripts/sync-web.sh`).
